# Emtional-code-in-Piano-music
## Project Overview

This project uses Python in TunePad to recreate Sections A, B and C of *Avid*. The complete arrangement is contained in one code file, including melody, accompaniment and bass.
## Repository Contents

[tunepad_project_132187.json] — Complete code for the piano music.

## How to Run
1. Open [TunePad](https://tunepad.com/) and paste the code file
